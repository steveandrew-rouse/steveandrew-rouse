# Security Policy

## Scope

This repository is a GitHub profile: Markdown, hand-authored SVG and a small GitHub Actions workflow. The realistic issues here are rendered-content injection in the README, malicious changes to `assets/`, and tampering with the snapshot workflow.

Projects linked from the profile are separate repositories and have their own security posture.

## Reporting a vulnerability

Please **do not** open a public issue. Report privately through either channel:

1. GitHub's [private vulnerability reporting](https://github.com/steveandrew-rouse/steveandrew-rouse/security/advisories/new) for this repository.
2. If that is unavailable, contact Steve Andrew Rouse directly through the links on the profile.

Include what you found, where it lives (file or URL), and the smallest reproduction you can manage. Expect an initial reply within a week.

## Please do not

- Open a pull request that demonstrates a vulnerability against the live profile.
- Test against, scan, or attempt to access systems you do not own.

## What to expect

- Acknowledgement of the report and a decision on severity.
- A fix and, where useful, a note in the change history crediting the reporter.
