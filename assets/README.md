# assets

Hand-authored, self-hosted artwork for the profile README. No third-party image services are involved, so these survive upstream outages.

| File | Purpose |
| :-- | :-- |
| `hud.svg` | Animated holographic HUD banner: matrix data columns, scanline sweep, glitch-ghost title, corner brackets, live readouts and a rotating core ring. |
| `rain.svg` | Matrix rain divider with 18 independently timed binary streams, used between README sections. |

## Implementation notes

- Pure SVG with SMIL (`<animate>`, `<animateTransform>`) — no JavaScript, no external fonts, no network calls.
- Palette is fixed to `#00ff41` on `#000000` so it reads as a terminal on both GitHub themes.
- Displayed with `<img width="100%">`; animations run inside the image context and respect reduced-motion preferences.
- Text uses a monospace stack, so glyph widths stay stable across platforms.

## Regeneration

The contribution snake is generated by `.github/workflows/snake.yml` using `Platane/snk` and published to the `output` branch every 12 hours:

```
https://raw.githubusercontent.com/steveandrew-rouse/steveandrew-rouse/output/github-snake-dark.svg
```

Everything else here is hand-authored; edit the SVG directly and keep the viewBox dimensions as declared.
