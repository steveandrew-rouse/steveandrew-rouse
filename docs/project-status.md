# Project register

This is the source of truth for what the profile's project register claims. The README summarises it; this page carries the detail. Labels are deliberately conservative:

| Label | Meaning |
| --- | --- |
| **Shipped** | Usable by someone other than the author, right now. |
| **In development** | The author uses it; parts are missing or break. |
| **Research** | Design, notes or a proof of concept. No working system yet. |

No percentage-complete numbers appear here on purpose. A percentage invites precision the work does not have.
